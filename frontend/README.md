# Frontend — Órdenes de Compra

React + Vite + Tailwind + shadcn/ui. Ver el README de la raíz para levantar el entorno completo.

```bash
npm install
npm run dev      # http://localhost:5173 (el backend debe estar en VITE_API_URL, por defecto :8080)
npm test
npm run build
```

Estructura: `src/app` (router, providers), `src/layouts`, `src/pages`, `src/features` (hooks de
TanStack Query por dominio), `src/components/ui` (shadcn) y `src/components/shared`.
